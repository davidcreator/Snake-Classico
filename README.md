# 🐍 Snake Clássico PRO — React 18 + Phaser 3

Aplicação de jogo 2D comercial desenvolvida com **React 18**, **Phaser 3**, **Vite** e **Tailwind CSS**.

---

## 🚀 Como Rodar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Compilar para produção
npm run build
```

Acesse em `http://localhost:5173`.
